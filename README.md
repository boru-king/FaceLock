# FaceLock（人脸锁）—— 人脸比对锁屏程序

> 基于 .NET 8 + Emgu.CV + ViewFaceCore(SeetaFace6) 的人脸 1:1 比对 Windows 小工具。
> 托盘常驻，按设定间隔弹窗比对一次——**是本人正常放行，不是本人自动锁定 Windows 工作站**。
>
> FaceLock — A face-verification auto-lock tray app for Windows: periodically checks the camera
> against your reference photos and locks the workstation when the face doesn't match.

**典型场景**：人离开工位后电脑自动"看脸"——人不在或不是本人，都会自动锁屏，防止未授权使用。
程序轻量常驻、按需开启摄像头、全程不保存任何摄像头画面（仅内存中比对，不落盘）。

## 功能一览

| 模块        | 说明                                                                      |
| --------- | ----------------------------------------------------------------------- |
| 🔐 人脸比对锁屏 | 定时抓取摄像头与底库照片 1:1 比对；**非本人或检测不到人脸（人不在场）均自动锁屏**（`user32!LockWorkStation`） |
| 🖥 托盘常驻   | 无常驻窗口；托盘图标右键菜单控制全部功能                                                    |
| 📸 按需开摄像头 | 仅比对瞬间开启摄像头（含 2 帧预热），用完立即释放，不长期占用                                        |
| 🪟 按需弹窗   | 比对时弹出命令行窗口显示过程明细，完成后自动关闭；可设为静默模式                                        |
| 🕒 间隔可调   | 比对间隔自定义（秒 / 分钟两档），设置即时生效                                                |
| 🖼 多底库照片  | `targets/` 文件夹支持多张参考照片（戴眼镜/不戴等），任一匹配即判本人                                |
| 🛡 操作密码   | 退出 / 设置需验证密码（PBKDF2-SHA256 哈希存储），防止被他人随意关闭                              |
| 🔒 防误关    | 任务管理器等常规手段无法结束本进程                                                       |
| 💤 低内存    | 人脸模型每轮比对时加载、结束即释放——空闲常驻内存约 130MB                                        |
| 📝 日志     | 每轮比对结果记录到 `facelock.log`，托盘一键查看                                         |

## 快速开始

1. 从 [`dist/`](./dist) 下载**全部分卷**（`.000`~`.004`）和 `解压还原.bat` 到同一文件夹；
2. 双击 `解压还原.bat`，自动合并分卷并解压出 `FaceLock/` 程序目录；
3. 把本人照片放进 `FaceLock\targets\`（建议 2~5 张，覆盖常出现的状态，如戴眼镜/不戴各一张）；
4. 双击 `FaceLock.exe`——程序常驻任务栏托盘，首次比对立即执行，此后按间隔循环。

> ⚠️ **测试前请确认记得 Windows 登录密码/PIN**——比对失败会立即锁屏。

## 功能使用详解

### 托盘菜单

| 菜单项 | 作用 | 需要密码 |
|---|---|---|
| 立即比对一次 | 立刻执行一轮比对（不等定时） | 否 |
| 设置... | 比对间隔（秒/分钟）、比对窗口显示开关 | ✅ |
| 修改密码... | 更换操作密码（先验证旧密码） | ✅ |
| 打开日志 | 查看 `facelock.log` 比对历史 | 否 |
| 退出 | 完全退出程序 | ✅ |

### 底库照片（targets/）

- **位置**：`FaceLock.exe` 同目录下的 `targets\` 文件夹；无该文件夹时退回单张 `target.jpg` 用法；
- **格式**：jpg / jpeg / png / bmp，**文件命名无限制**；
- **数量**：不限；覆盖你常出现的样子越多，识别通过率越高（戴眼镜、不同光线/发型等各来一张）；
- **加载**：程序启动时一次性全部加载，**中途增删照片需重启程序**；
- **判定**：每轮的每一帧与**每张**底库照片逐一比对，任一匹配即算本人。

### 比对机制（工作原理）

每轮比对：加载人脸模型 → 提取底库特征 → 打开摄像头 → 丢弃 2 帧预热 → 连抓 **3 帧**（间隔 1.5 秒）
→ 每帧与每张底库照片逐一比对 → 判定 → 释放摄像头与模型。

| 比对结果 | 行为 |
|---|---|
| 任一帧匹配任一底库 | ✅ 放行（本人） |
| 有人脸但均不匹配 | 🔒 锁屏（陌生人） |
| 3 帧全部检测不到人脸 | 🔒 锁屏（人不在场——离位防护核心） |
| 摄像头读帧全部失败 | ⏭ 跳过本轮并记日志（设备故障≠未授权） |

采用"多帧 + 多底库"的宽松判定，是为了对抗单帧比对在阈值附近的抖动（光照、角度、表情都会影响单帧结果），
优先避免"自己人被误锁"。摄像头画面全程只存在于内存中，比对完即释放，**不写入磁盘**；
人脸模型同样按轮加载/释放，空闲内存保持低位。

## 配置文件参考

`config.json`（与 exe 同目录）由程序自动创建/更新，一般无需手改：

```json
{
  "IntervalValue": 3,
  "IntervalUnit": "minutes",
  "ShowConsoleWindow": true,
  "PasswordHash": "…",
  "PasswordSalt": "…"
}
```

| 字段 | 含义 | 取值 |
|---|---|---|
| `IntervalValue` + `IntervalUnit` | 比对间隔 | 秒（5~3600）/ 分钟（1~10080） |
| `ShowConsoleWindow` | 比对时是否弹出命令行窗口 | true / false |
| `PasswordHash` / `PasswordSalt` | 操作密码哈希（PBKDF2-SHA256，**不存明文**） | 由程序写入 |

## 注意事项

1. **锁屏是真实发生的**：比对失败立即等同 Win+L。测试阶段务必确认记得登录密码/PIN；
2. **先坐好再启动**：首次比对在启动后立刻执行；建议先坐到摄像头前，或稍后用托盘【立即比对一次】手动触发；
   离位防护提示：**人不在摄像头视野内会触发锁屏**（这正是设计目的）；若整轮比对期间长时间低头/侧脸
   导致 3 帧均未识别到人脸，也会锁屏，回来解锁即可；
3. **识别率调优**：眼镜、口罩、刘海、逆光会显著拉低相似度——底库照片请覆盖你常出现的状态；
   若偶发误锁，优先补照片，其次调大比对间隔；
4. **摄像头占用**：其他软件（会议/直播）占用摄像头时，本程序读帧失败会跳过本轮并记录日志，不会崩溃；
5. **防误关的边界**：任务管理器/任务栏右键**无法**结束本进程；但**管理员权限**可以（作为密码遗失时的恢复途径），
   重启电脑也会正常结束程序。这是"防误关"而非"防管理员"；
6. **密码保管**：操作密码遗失时需管理员权限结束进程并删除 `config.json` 才能重置（详见 FAQ）；
7. **安全软件提示**：无签名的单文件 exe 加上锁屏行为可能被 Windows Defender 误报，
   属于行为敏感性提示，可加白名单或自行代码签名；
8. **隐私**：程序不上传任何数据、不保存摄像头画面（仅内存比对）；`targets/` 内的照片请勿随程序包一起分发。

## 常见问题（FAQ）

**Q：忘记操作密码怎么办？**
A：① 重启电脑可临时结束程序；② 以**管理员身份**打开任务管理器或命令行结束 `FaceLock.exe` 进程
（管理员权限不受防误关限制）；③ 删除程序目录下 `config.json`；④ 重新启动程序，首次退出/设置时会引导创建新密码。

**Q：自己人也被误锁了？**
A：单帧比对在阈值附近存在抖动。三步优化：① `targets/` 补充更多本人照片（不同眼镜/光线/角度各一张）；
② 托盘【设置】里把间隔调大；③ 确保摄像头光线充足、正对坐姿。

**Q：如何开机自动启动？**
A：按 `Win+R` 输入 `shell:startup` 打开启动文件夹，把 `FaceLock.exe` 的**快捷方式**放进去即可。
程序本体建议保留在固定目录，移动目录后需重新创建快捷方式。

**Q：如何完全退出 / 卸载？**
A：退出：托盘右键 → 退出（需密码）。卸载：直接删除整个程序文件夹即可——
程序不写注册表、不注册服务、不做任何系统级残留（设置与日志都在程序目录内）。

**Q：`facelock.log` 会无限变大吗？**
A：按每 3 分钟一轮估算每天约产生数百 KB 文本，可随时手动删除，程序会自动重建。

**Q：摄像头被其他软件占用？**
A：本程序读帧失败时跳过本轮并在日志中提示，不退出、不崩溃；释放摄像头后下一轮自动恢复。

**Q：能不能改成"不锁屏只提醒"？**
A：可以——项目开源，锁屏逻辑在 `Comparator.cs` 中显式调用（陌生人/无人两分支），改成气泡提醒/声音提示均可。

**Q：支持多摄像头 / 指定摄像头吗？**
A：当前版本固定使用 0 号摄像头（系统默认）。如需指定，可修改 `Comparator.cs` 中 `VideoCapture` 的索引参数。
